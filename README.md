# Scalable Data Processing Pipeline

## Overview
Built a scalable pipeline to process 5M+ records efficiently using chunk-based processing.

## Features
- Chunk processing (low memory)
- Data validation
- Logging & error handling
- SQL database storage

## Tech Stack
Python, Pandas, SQL, Unix, AWS EC2

## How to Run
1. python3 generate_data.py
2. python3 src/main.py

## Output
- SQLite DB: data.db
- Logs: logs/pipeline.log
